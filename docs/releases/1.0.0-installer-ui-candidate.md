The approved presentation contract is owned by
[INSTALLER_DESIGN.md](../INSTALLER_DESIGN.md): a full-width banner with preserved
artwork proportions, Install/Maintenance tabs, per-root game cards, Requiem
nested under Black Plague, per-game extras, recommended graphics checked by
default, advanced configuration scope and one state-dependent primary action.
Maintenance handles checks, repair, component removal, diagnostics and recovery
of interrupted transactions. English is the default; switching to Español
selects editable translations. Returning to English preserves owned and chosen
components. The transaction engines and game ownership boundaries remain intact.

Fresh verification:

- Presentation state/routing tests passed in Windows PowerShell 5.1 and
  PowerShell 7: fresh/owned/older/damaged/interrupted/unsupported installations,
  independent copies, expansion selection and recorded maintenance ownership
  when a foreign recognized executable replaces the launcher.
- Actual WinForms controls passed English/Spanish switching, editable choices,
  refresh, maintenance exclusions, Modify target transfer, full-width cards and
  banner, primary visibility, and Requiem-only removal through the real dialog.
  English/Spanish Install and Maintenance renders were inspected.
- GUI orchestration tests injected failures at the external selector boundary:
  all roots preflight before the first write; later preflight failure performs
  zero writes; later execution failure reports completed and failed root paths.
- The expansion-removal regression was reproduced against the preceding EXE:
  removing Requiem also removed Black Plague Spanish. Both explicit and numbered
  selector routes now preserve the recorded base translation. Isolated real
  transaction fixtures passed removal and exact restoration against this EXE.
- Deterministic combined packaging, Overture/shared B/R install/repair/restore,
  component transitions and all eight controller profiles passed.
- Root CTest passed 49/49 before packaging. Product packaging ran Overture's
  Release build and 289 checks, with zero failures; all 16 VR shaders compiled
  offline and 231 selected JPEGs decoded successfully.
- Source/identity/notices, outer checksums and absence of developer/private
  payload checks passed. The EXE copied to the user download path has the exact
  hash above and is the only file in that public download directory.
- Delivered EXE standalone startup, extraction/integrity, bilingual GUI and
  embedded dependency checks passed without an adjacent checkout or .NET runtime.
- This exact EXE passed topology A–F: isolated Overture, isolated Black Plague,
  shared B/R, both independent roots, full trilogy and later additions, including
  install/verify/repair, dependent/independent removal and exact restoration.

A fresh read-only review identified six important cases; they were corrected
and covered by state, WinForms and transaction regression checks. No minor
findings were deferred. Fixture deployments use isolated default settings and
never edit the real Documents configuration.

These checks do not demonstrate a separate clean PC, physical DPI/keyboard UI
acceptance or headset gameplay. The preceding door-nudge and initial Requiem
height corrections remain included but still need headset confirmation. The
