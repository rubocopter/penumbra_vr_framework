# Penumbra VR Framework 1.0.13 — Requiem maintenance candidate

Released 2026-10-27 as a **pre-release. Headset validation pending.**

**The developer has not played or tested this version in-game or in a VR
headset. Both level08 corrections below have automated host validation only.
Completion of Requiem level08 has not been demonstrated.** This candidate makes
the corrections available for players to continue and report actual results.

## Requiem level08 — Steam-themed level

- Restore a bounded native inventory-pickup route for the glowing orb behind
  the shack hatch. The controller ray retains native item eligibility and
  character-to-hit reach, a 1.9 m shared range cap, and independent hand/head
  visibility. Character-only barriers remain intact; walls, the box and hatch
  continue to obstruct selection. Move the box and open the hatch normally.
- Recognize the keypad's native ScreenGui before choosing the VR input context
  and deliver the tracked pointer through the existing native GUI interface.
  Preserve native digit callbacks, validation and Close/Escape behavior. Release
  held UI select/back buttons on focus or tracking loss to avoid retained clicks.

**Both changes remain pending validation in a VR headset.** They do not bypass
puzzle conditions, remove collision, move the orb or change the keypad solution.
The native Escape branch closes ScreenGui directly; no generic pause/reset
workaround was added.

## Preserved corrections

Includes all preceding maintenance fixes, including sphere throwing with B,
controller-owned aim, lever constraints and direction, drawer endpoints, walking,
jumping and native Grab/Move/Push lifecycles. The protected throwing and mechanism
functions are unchanged by the level08 corrections.

Caelus reports that sphere throwing and levers now work perfectly after the
previous corrections. That is scoped tester feedback without a pinned installed
artifact hash; it is not developer testing or validation of this new package.

## Validation and limits

The interaction implementation passed **79 Framework host tests in both Debug
and Release** and **298 Overture Release checks**. Targeted regressions cover
pickup reach/eligibility/occlusion and GUI context, pointer, button edges,
cancel/re-entry and focus recovery. Native boundaries in consumer tests are
characterized fixtures; the actual level scripts and puzzle progression were
not executed. Final installer checks and hashes are recorded in the
[artifact validation record](1.0.13-validation.json).

Level04 water/crouch recovery and the intermittent SDL startup crash have no
confirmed fix. Level05 buttons/cabinets, broader progression, other controller
hardware and independent clean-PC acceptance retain their separate open gates.
