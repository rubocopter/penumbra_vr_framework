Historical v1.0.4 notes. This release download has been superseded by
[the consolidated v1.0.5 update](1.0.5.md); the validation below applies only
to the original artifact.

This is a focused follow-up to the external Valve Index v1.0.3 retest. Black
Plague and Requiem were reported to work as intended overall; v1.0.4 addresses
the two remaining regressions without reopening unrelated controller work.

## Changes

- **Overture:** removed the v1.0.3 in-game **Controller bindings (SteamVR)**
  shortcut from the legacy Controls menu after the tester reported a crash just
  before the main menu. The corrected Index defaults and independent inactive
  Move/Turn stick fallback remain intact. Overture bindings can still be edited
  from SteamVR's dashboard.
- **Black Plague:** added a proper VR adapter for native `Push=1` interactions,
  including the heavy crate in the tutorial. VR-origin Push stores the tracked
  palm contact relative to the body and applies the proven Overture/Rework 300 N
  horizontal force while retaining Black Plague's native Enter/Exit lifecycle.
- Requiem and Black Plague's other gameplay paths are unchanged by this patch.

## Download and update

[Download the current consolidated update](https://github.com/rubocopter/penumbra_vr_framework/releases/tag/v1.0.5).

Close the games, run the v1.0.4 installer and update the detected installations.
If SteamVR retained an older custom Index layout, reselect the bundled default or
keep the custom layout with Move/Turn bound to the stick Position (`Vector2`)
actions. Overture now uses the SteamVR dashboard editor rather than an in-game
binding shortcut.
