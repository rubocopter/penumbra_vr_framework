# Penumbra VR Framework 1.0.12 — Interaction maintenance

Released 2026-10-27. **Headset validation pending.**

**The developer has not played or tested this version in-game or in a VR
headset.** The corrections have automated host validation only. This maintenance
release makes the current fixes available so players can continue their games
and report whether the affected interactions now work. It does not establish
that the reported progression blockers are resolved in the actual game.

## Requiem throwing and B / Examine

- Aim native assisted throws with the controller holding the object, including
  free-body Move and Push interactions. Push keeps the original game's
  horizontal launch convention; native throw strength and puzzle rules remain.
- Use the current controller direction after turning or ladder travel instead
  of reusing the camera direction captured when the interaction began.
- Prevent Push cancellation or ordinary release from accidentally triggering
  the B / Examine launch. Handle stale tracking and Interact/Examine ordering
  without falling back to an outdated camera direction.
- Retain the earlier gesture-release and independent Examine/ladder fixes.

## Levers, switches and native buttons

- Make Requiem consume the centre-of-mass hinge correction already used by
  Black Plague. The shared correction also serves Framework-owned Overture.
  It addresses a reproduced disagreement between the VR velocity command and
  the native hinge constraint, without changing joint limits or script events.
- Restore Rework's separate head-to-visible-palm selection query for Requiem
  native interaction areas. It keeps native range and line-of-sight checks;
  ordinary physical grabs keep their existing reach.
- Compare area and physical contact priority from a common origin instead of
  mixing palm distances with distances from offset rays.
- Retain the existing filing-cabinet slider endpoint correction from v1.0.11.
  No second drawer workaround or global lever-direction inversion was added.

## Validation and remaining issues

Debug and Release Framework builds pass all **78 automated tests**; the
Overture Release product passes **298 checks**. New regressions reproduce the
previous pivot drift and selection failures before correction. The mechanism
test uses the shipped Newton library; native selection/action boundaries in
consumer tests are fixtures. Neither is a running-game or headset test.

The following remain unverified or unresolved:

- Actual lever attachment, trembling, comfort and direction on the reported
  mechanisms. Individual mechanisms retain their authored native behavior.
- Requiem level03 bottle progression, level05 generator/hatch/door buttons and
  cabinet operation, and level07 sphere progression after the throwing changes.
- The level07 sphere's physical stoppage at the opening: no confirmed cause or
  collision/puzzle change.
- The level04 underwater crouch/recovery problem and intermittent SDL startup
  crash: **no confirmed fix**.
- Other controller hardware, independent clean-PC acceptance and full-game
  progression. Historical headset acceptance does not transfer to this build.
