# Penumbra VR Framework v1.0.0

Released 2026-09-29.

This is the first public Penumbra VR Framework release for **Penumbra:
Overture, Black Plague and Requiem**. It packages the three integrations behind
one bilingual graphical installer while preserving their separate game/runtime
boundaries.

## Highlights

- Unified installation for Overture and the shared Black Plague/Requiem root.
- Stereoscopic rendering, head tracking, room-scale movement and tracked hands.
- Motion-controller locomotion, interaction, inventory/notebook and game-specific
  puzzle integration.
- Eight bundled SteamVR controller binding profiles.
- Optional Spanish localization components and Overture texture enhancements.
- Recommended VR graphics settings with user calibration/settings preservation.
- Transactional install/update/repair/recovery/uninstall with verified backups
  and exact restore ownership.
- Exact-build validation for the binary-integrated games and fail-closed handling
  of unknown executables.
- Matching source, notices, checksums and build report for the release.

## Acceptance evidence

The exact Setup EXE passed deterministic packaging and standalone
extraction/integrity checks, bilingual GUI/dependency checks, topology A–F
installation scenarios, component transitions, repair/recovery/removal, all
eight bundled controller profiles and exact restoration. Its build record also
includes the root CTest suite. A final full Overture Release rebuild completed,
verified the executable as Large Address Aware and passed its product validation
suite with **289 checks and 0 failures**.

The maintainer additionally repeated real install/uninstall flows with this EXE
and successfully entered Overture, Black Plague and Requiem. This is real
release acceptance on the maintainer setup, not an independent clean-PC or
universal headset/controller certification.

## Known limitations

- Requiem can fail intermittently during startup; the cause remains unresolved
  and unattributed.
- Black Plague can produce small vertical hops while touching ventilation walls.
- Requiem still has minor finger/contact intersections, resistant monolith rings
  and possible stacked-block displacement while climbing.
- Broader progression/interaction regression remains incomplete in both binary
  games.
- Non-Sense controller families are bundled but have not been personally
  hardware-validated. Vive/WMR profiles have documented action omissions.
- Independent clean-PC coverage remains limited. Validation levels are tracked
  separately from release/publication state.
