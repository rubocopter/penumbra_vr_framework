Released 2026-10-04. This update brings together all improvements since v1.0.0
and replaces the intermediate v1.0.1–v1.0.4 releases.

- **Controls:** corrected Valve Index thumbsticks and conflicting button bindings,
  improved pointing defaults, and added a reference for all eight controller
  profiles. Overture recovers missing stick actions independently.
- **Overture:** improved drawer and mechanism selection, removed the binding-menu
  shortcut associated with the reported pre-menu crash, and corrected focus-loss
  handling and stale controller aim poses.
- **Black Plague:** improved tracked-hand pushing and stick direction for heavy
  objects, preserved eye height while turning, and corrected mass-amplified hand
  nudges. Held objects now survive temporary presentation gaps while tracking
  remains valid.
- **Performance:** reduced diagnostic logging stalls. The maintainer completed
  the Black Plague tutorial without the previously reported freezes or box drops.
- **Installer:** clearer preparation/progress feedback and responsive background
  operations, with existing settings, optional components and backups preserved.

[Download PenumbraVR-Setup-1.0.5.exe](https://github.com/rubocopter/penumbra_vr_framework/releases/download/v1.0.5/PenumbraVR-Setup-1.0.5.exe).
Close the games and run the installer to update. If SteamVR retains an older
custom binding, select the updated bundled default for that game and restart it.
Matching source, checksums and a build report are included with the release.

Overture and the Black Plague tutorial have maintainer gameplay feedback on the
preceding local fixes; that does not validate every game or controller on this
new installer. Excessive Black Plague collision recoil, intermittent Requiem
startup failure and the reported finger mismatch remain under investigation.
