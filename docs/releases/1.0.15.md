# v1.0.15 — Trilogy maintenance and experimental Neural

This pre-release includes all unreleased 1.0.14 maintenance work and the latest
trilogy corrections. It is not full-playthrough or universal-headset validation.

- Requiem cable/anchored-rope interaction: the maintainer reports the cable and
  corrected rope working. Oil ignition and complete puzzle progression remain
  separate acceptance gates.
- Centered, enlarged messages/narration/video subtitles across the three games,
  including Radio/ScreenGui and native introduction/ending text. Long ending
  pages fit the HUD without changing reveal timing. New headset retests remain.
- Trigger-clickable minus/plus controls in the VR menus.
- Shared seated-height correction: leaning down no longer recalibrates the
  chair baseline and counteracts the physical reach. Host-tested in all three
  consumers; new headset acceptance pending.
- Render scale uses SteamVR's recommendation and each eye's projection. The
  multiplier requires restarting in all three games. Requiem's live resizing
  was rejected after severe headset distortion; the active pair now stays fixed.

## Neural — experimental, optional, disabled by default

Setup includes the x64 companion and DirectNR forwarder. No compilation is
needed. After installing VR, open **Maintenance**, select an installed game,
then **Import Neural (experimental)** and select your local `nvngx_dlssnr.dll`.
The NVIDIA model is not included or downloaded by this release. Requirements
and guidance for obtaining it are maintained by
[DirectNR](https://github.com/lowpoplabs/nr-bridge#prerequisites); consult the
[NVIDIA DLSS portal](https://developer.nvidia.com/rtx/dlss) and applicable terms.
Do not substitute a Super Resolution, Frame Generation or Ray Reconstruction DLL.

Open **VR Settings → Neural** in each game. Values are stored independently and
apply during play. A moderate starting point is internal height **896**, scale
**50%**, intensity **25%**, **1** pass, style **0**, center **100%**, outer **Off**.
These are tuning suggestions, not a quality/performance guarantee. The internal
height is an inference proxy; it does not replace SteamVR's game render size.

Missing helper/model or unsupported initialization reports **Unavailable** and
keeps the original stereo image. A late frame reports **Recovering**, discards
stale output and can resume; a worker fault/stall bypasses processing. Turn it
off to restore original stereo. Changing the game render multiplier is separate
and requires restart. The order remains game → Neural → optional external frame
generation → headset; generated intermediate frames do not re-enter Neural.

Neural estimates rotation motion and uses constant depth. It has no real object
motion vectors/full scene depth. Image quality, lighting, stereo consistency,
latency and performance may be worse; this is not an official NVIDIA integration
or a claim of visual improvement. Compatible NVIDIA hardware/runtime is required.
Use **Remove Neural** in Maintenance to restore the previous local configuration;
full game-root uninstall also removes owned optional Neural. Modified owned files
are rejected rather than silently overwritten/deleted. Removing only Requiem
preserves the shared Black Plague Neural component.

CLI equivalent from the extracted package:

```powershell
.\tools\Install-PenumbraNeural.ps1 -GamePath 'D:\Games\Penumbra\redist' -ModelPath 'D:\MyRuntime\nvngx_dlssnr.dll'
.\tools\Install-PenumbraNeural.ps1 -GamePath 'D:\Games\Penumbra\redist' -Restore
```

The new Setup, matching Source ZIP, build report and SHA256SUMS accompany this
release. Automated checks do not establish headset comfort or clean-PC readiness.
Requiem level04 water recovery and intermittent SDL startup crash remain unresolved.
