# Penumbra VR Framework v1.0.3

Released 2026-10-03. This update bundles the offline corrections following the
external Index retest of v1.0.2. It addresses a reproduced Black Plague height
change during turning, missing Overture stick actions and overlapping controller
defaults. These corrections are host-tested; current-build hardware acceptance
remains open.

## Changes

- Black Plague keeps calibrated eye height when turning changes the yaw epoch
  before the native body sample catches up. Only old horizontal prediction is
  suppressed; tracking-origin discontinuities and collision boundaries keep
  their existing guards. This fixes the reproduced height-switching path, not
  a proven cause of the reporter's low resting height.
- Overture can recover each inactive Move/Turn action through its existing
  legacy analog path while other actions work. Active custom actions, including
  neutral values, remain authoritative. Legacy clicks are not imported because
  the Index legacy map can synthesize clicks from stick deflection.
- Index quick light uses the offhand grip instead of sharing the interaction
  trigger. Grip/trackpad presses use Valve's explicit force thresholds; pause
  uses the right trackpad and recenter the left, avoiding the reserved system
  button. Touch/Pico recenter is unassigned to avoid gameplay overlaps or
  nonexistent buttons. WMR's mirrored pause/recenter overlap is removed.
- Pointing defaults use the declared tip pose. Both handedness layouts and both
  distributed binding trees remain aligned. Vive/WMR compatibility exceptions
  are documented rather than presented as device validation.
- Overture **Options > Controls** and Black Plague **Options > VR Settings**
  offer **Controller bindings (SteamVR)** to inspect/edit the actual active
  layout. Requiem uses the SteamVR dashboard. The [controls reference](../CONTROLLER_BINDINGS.md)
  is generated and checked against all eight default graphs.

## Download and update

[Download PenumbraVR-Setup-1.0.3.exe](https://github.com/rubocopter/penumbra_vr_framework/releases/download/v1.0.3/PenumbraVR-Setup-1.0.3.exe).

Close the games, run the installer and update the installed games. In SteamVR,
select the updated bundled default for each affected game and restart the game.
Saved custom layouts are preserved and can otherwise hide the new defaults.
Move/Turn use Joystick **Position** (`Vector2`); crouch uses a separate **Click**.
If playing seated, select **Seated** play mode in the game's VR settings where
available; personal calibration is preserved by the installer.

The release includes matching source, pinned upstream sources, checksums and a
build report. The installer does not launch games.

## Validation and limitations

The Framework suite has 55 tests and Overture has 298 checks. Regressions cover
the real Black Plague placement function across turning/origin changes, independent
stick fallback, controller conflicts/force inputs and the generated reference.
Exact artifact and packaging evidence is recorded in [1.0.3-validation.json](1.0.3-validation.json).

The reporter confirmed Requiem movement/turning and Black Plague stick input on
v1.0.2; this does not validate v1.0.3 or other gameplay paths. No new headset
acceptance is claimed. Overture recovery applies to inactive actions; an active
action returning zero still needs a correct saved binding. The cause of the
reporter's low resting height is not established. Finger articulation remains
unresolved and deferred as nonblocking feedback. Intermittent Requiem startup
failure and other [recorded limitations](../TRILOGY_PARITY_PLAN.md) remain open.
