## Installation and removal

- Recover interrupted Black Plague/Requiem installs using the current journal,
  while retaining validation of older journals, paths, snapshots and hashes.
- Uninstall tolerates preference files deleted by the user, rejects directory
  and junction conflicts, and verifies the original ALUT bytes before removing
  the backup. Failed restoration remains recoverable.
- When uninstall removes an owned Spanish translation without an original,
  repair that specific selection in default/personal settings to the game's
  bundled English language. Keep valid custom languages and later preferences;
  include the affected settings in transaction rollback.
- Setup extraction accepts new destinations with a trailing slash or backslash.
  Existing destinations and malformed payloads remain rejected.

## Overture input

- Keep the acquiring interaction hand until the logical hold ends, including
  a second trigger press and tracking-loss cancellation.
- Emit release edges when an individual SteamVR binding becomes inactive.
- Use the same tracked hand for UI pointer geometry and buttons, including the
  alternate hand and legacy fallback. A hand switch releases the old drag and
  waits for a fresh press.
- Recenter orientation before a player body exists and from the current head
  pose while paused, preserving height calibration and subsequent movement.
- Correct the diagnostic that rejects an obsolete local deployment package.

## Requiem interactions and cleanup

- Preserve native foreground occlusion independently on each hand ray; an
  unobstructed finger ray can still acquire its own valid target.
- Keep native ScriptArea selection and area/solid arbitration for the reported
  level05 generator, hatch and door buttons, including palm-overlap priority.
- Temporarily suspend native drawer endpoint stickiness only for a VR-owned
  Move child attached to a static/world parent. Restore unchanged values before
  native Leave; keep joints, limits, scripts and overrides authoritative.
- Drain pending and committed native interactions before removing their Leave
  hooks. Destroy palm shapes on their native owning thread, including menu or
  player-less updates. Timeout/failure retains a retryable partial teardown.
- Consume turn-reset requests on the native update owner instead of modifying
  its state concurrently from a control thread.
- Add physical capsule-height diagnostics for the level04 sewer report.

## Evidence and remaining problems

The fixes have actual-consumer and isolated filesystem host regressions:
**77 Framework tests in Release and Debug**, plus **298 Overture checks**.
The versioned release process separately verifies the exact final Setup,
source archive, pinned dependencies, PE identities and installer transactions.
These results do not establish new in-game/headset acceptance.

**Requiem level04 water recovery has no confirmed fix.** This release does not
alter buoyancy, gravity or vertical VR impulses. Level05 repeated button
activation and drawer endpoints, level03 bottle progression/throw/cue usability,
and new Overture input behavior still need focused headset feedback. The
intermittent Requiem SDL startup crash remains unresolved. Existing historical
headset acceptance does not transfer automatically to the new binaries.

[Download PenumbraVR-Setup-1.0.11.exe](https://github.com/rubocopter/penumbra_vr_framework/releases/download/v1.0.11/PenumbraVR-Setup-1.0.11.exe).
Close all affected games before updating. Matching committed source, dependency
sources, build provenance and SHA-256 checksums accompany the unified installer.
