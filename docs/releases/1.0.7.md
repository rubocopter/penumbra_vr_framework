Released 2026-10-10.

## Input reliability

- **Black Plague and Requiem:** digital actions now emit a release when an
  individual binding becomes inactive or stops reporting its release edge.
  This prevents interaction and UI actions from remaining held. Context and
  dominant-hand changes retain the existing suppression of unintended edges.
- **Movement settings:** the configured movement dead zone survives temporary
  focus loss, input-read failure and complete binding inactivity. Returning to
  gameplay keeps the same stick response; an explicit reset still uses defaults.
- **Analog safety:** non-finite axes are rejected, non-finite dead-zone values
  use the schema default, and finite axes are bounded before radial rescaling.
  Controller freshness checks reuse the already validated grip-pose flags.

## Trilogy acceptance and maintenance

- The maintainer accepted the locally installed trilogy checklist, including
  consistent first-level English/Spanish VR Settings, BP mixed-input obstacle
  movement, Overture edge visibility/reach and input/focus recovery. The scoped
  [acceptance record](1.0.7-headset-acceptance.json) identifies those exact
  installed binaries. Device-specific conditional tests are kept separate.
- Update the capability ledger, configuration guide, regression checklist,

- Add Windows CI fixtures for installer configuration, prerequisites, release
  identity, bilingual UI state and diagnostics/privacy without game binaries or
  VR hardware.
- Supply the unified installer, exact committed source, pinned dependency
  sources, checksums and build report.

[Download PenumbraVR-Setup-1.0.7.exe](https://github.com/rubocopter/penumbra_vr_framework/releases/download/v1.0.7/PenumbraVR-Setup-1.0.7.exe).
Close the games before updating. Existing settings, selected translations,
Overture texture enhancements and original-file backups are retained by the
installer's recorded component selections.

The reported Requiem starts passed on the tested installation. Its intermittent
startup crash still has no demonstrated root-cause fix. Broader progression,
other controller families, Index finger feedback and independent clean-PC
coverage remain open. Acceptance of the preceding local build does not imply
headset testing of the newly versioned Setup artifact.

## Español

Se corrigen acciones de interacción y de interfaz que podían quedarse pulsadas
al perder un binding individual. Black Plague y Requiem conservan la zona muerta
del joystick después de una pérdida temporal de foco o de entrada. También se
protege el tratamiento de valores analógicos inválidos.

El mantenedor ha validado la lista de pruebas de los tres juegos instalados:
menús VR coherentes en inglés/español, movimiento cerca de obstáculos en BP,
visibilidad y alcance en Overture y recuperación de entrada. La documentación
recoge esa validación con las huellas de los binarios probados. Se amplían las
pruebas automáticas del instalador y de diagnósticos en Windows.

Se publica el instalador unificado junto con el código fuente correspondiente,
las fuentes de dependencias, las sumas SHA-256 y el informe de compilación.
El fallo intermitente de arranque de Requiem sigue bajo investigación; esta
actualización no anuncia una corrección de su causa.
