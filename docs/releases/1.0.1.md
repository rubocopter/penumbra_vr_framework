Historical v1.0.1 notes. This release download has been superseded by
[the consolidated v1.0.5 update](1.0.5.md); the validation below applies only
to the original artifact.

Released 2026-10-03. This patch improves Overture acquisition and installer
responsiveness. The maintainer installed the exact candidate and accepted an
Overture headset play session including the initial drawer, crank and other
mechanisms. The candidate is published unchanged to preserve that evidence.

## Changes

- Improved physical interaction in Overture. Sibling physics bodies belonging
  to the same mechanism no longer block selection of its wheel or handle.
- Fixed a second acquisition defect around drawers and nearby objects: a hidden
  overlap no longer prevents selection of another accessible contact within the
  hand volume. Inventory-item priority and the existing reach/collision bounds
  are preserved.
- Corrected the Oculus Touch aim binding to SteamVR's tip pose in the Overture
  and shared controller profiles.
- Setup now displays **Preparing installation / Preparando la instalación**
  during extraction and checksum verification and keeps it visible until the
  main installer appears. Avoided recompressing the ZIP payload inside the
  executable, reducing work before the first window can appear.
- Installer checks, installation, maintenance and final verification now run in
  background runspaces. An animated waiting dialog keeps repainting during
  long operations; errors and partial completion still identify affected games.
- Black Plague render telemetry no longer waits on a busy diagnostic lock,
  preventing diagnostics from stalling a VR frame.
- Executable, installer and package metadata now identify this patch as 1.0.1.

## Validation and remaining checks

Host validation covers the 51-test Framework suite, Overture's 289 checks,
visibility ranking in both candidate orders, bilingual WinForms controls,
background-worker responsiveness/errors, all-root preflight and partial failure.
The bootstrap smoke exercises embedded extraction, cleanup and the preparation
window. Package checks validate identity, hashes, matching source and absence of
private/developer payloads.

The exact installer passed topology A-F: isolated and combined games,
shared-root deduplication, Requiem-layer removal, repair and exact restoration
with synthetic content/runtime fixtures. No game was launched by automation.

On 2026-10-03 the maintainer used this installer and played Overture beyond a
single drawer check, repeated crank/mechanism interactions and accepted the
result. The installed Overture executable matches SHA-256 `5DCCCD1EBCEACFBA10D12C964F7B529A711331915930B2D85ADD3FA29E429097`.
Quest 3 pointer alignment was not separately reported in this acceptance and
remains a focused hardware retest. Black Plague's telemetry change retains its
host-tested status; independent clean-PC coverage remains open.
