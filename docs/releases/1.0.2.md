Historical v1.0.2 notes. This release download has been superseded by
[the consolidated v1.0.5 update](1.0.5.md); the validation below applies only
to the original artifact.

Released 2026-10-03. This patch corrects the bundled Valve Index thumbstick
bindings for Overture, Black Plague and Requiem so Index users can retest the
reported movement/turning failure. The correction is host-tested; physical
Index confirmation remains pending.

## Changes

- Index (`knuckles`) defaults now use SteamVR's `/input/thumbstick` component
  instead of the inherited Touch-style `/input/joystick` path.
- Both right- and left-handed layouts include corrected movement, turning,
  sprint/crouch stick clicks and inventory drag clicks. Other controller
  families keep their own input paths.
- A regression generates the defaults and checks both distributed binding
  trees, including the mirrored layouts and preservation of Touch movement.
- Updated input troubleshooting and the headset test procedure for the
  external Index feedback.
- Installer, game binaries and package metadata identify this patch as 1.0.2.

All v1.0.1 gameplay and installer improvements remain included.

## Download and update

[Download the current consolidated update](https://github.com/rubocopter/penumbra_vr_framework/releases/tag/v1.0.5).

Close the games, run the new installer, select the installed games and use its
update action. SteamVR saves custom bindings separately; the installer preserves
them. After updating, select the bundled default again in SteamVR's controller
bindings for each affected game, then restart the game. Resetting to an older
installed default will retain the incorrect component path.

To preserve a custom layout, edit only the affected stick bindings instead.
Use **Joystick** mode and its **Position** output for **Move** and **Turn** in
the active gameplay set. `Vector2` is the expected two-axis action type;
movement/turning do not bind to the boolean **Click** output. Left-handed
gameplay mirrors the stick assignments.

The release also provides `PenumbraVR-Source-1.0.2.zip`, `SHA256SUMS.txt` and
`build-report.json` for matching source, pinned upstream inputs, artifact hashes
and build provenance. The installer does not launch a game.

## Validation and known limitations

The 52-test Framework suite passes, including the new Index binding regression,
hand input/conditioning and real OpenGL articulation tests. Overture's 289
checks pass. The exact Setup EXE passes standalone extraction/startup without
an installed .NET runtime, package/checksum/source verification and installation
topologies A-F with synthetic content/runtime fixtures.

Upgrade fixtures use the released v1.0.1 installer followed by this v1.0.2
installer in Overture and the shared Black Plague/Requiem root. All eight
defaults match the new package by hash; the Index graph changes to thumbstick,
repair restores a deliberately damaged graph, and uninstall restores original
executables while preserving a user-owned marker. Requiem verification passes
in the shared root. No game was launched by automation. Physical Index
movement, turning and UI retesting remain required in each game. A passing host
test does not establish Index hardware support.

The reported index/pinky finger mismatch remains unresolved and is **not fixed
by this release**. Current code preserves OpenVR's documented finger channel
order. Please compare bare-hand gestures, one finger at a time, in SteamVR's own
skeletal-hand display and inside the game, with no tool held. Report the
physical finger moved, the visible finger that responds, the game and mod
version. Overture's reported difficulty manually remapping the stick also needs
hardware reproduction independently of the corrected default paths.

Earlier maintainer headset acceptance belongs to the exact v1.0.1 artifact;
this new installer has no new headset acceptance. Intermittent Requiem startup
failure, Black Plague ventilation-wall mini-hops and other documented gameplay
limitations remain. See [build evidence](../SUPPORTED_BUILDS.md) and the
[controller ledger](../TRILOGY_PARITY_PLAN.md#controller-profiles-and-distribution).
